# Sistema de Mesa de Partes

## Descripción
Prototipo académico desarrollado en Python para registrar y gestionar expedientes de una municipalidad.

## Objetivo
Organizar el registro, la búsqueda y el ordenamiento de expedientes, así como la generación de constancias de recepción.

## Funcionalidades
- Registrar expedientes.
- Validar los datos ingresados.
- Validar el DNI y la fecha.
- Generar códigos para los expedientes.
- Buscar expedientes por código.
- Listar y ordenar expedientes.
- Generar constancias de recepción.
- Guardar los registros en un archivo CSV.

## Tecnologías
- Python 3.
- Git y GitHub.

## Organización de los archivos
- `main.py`: menú principal y ejecución del sistema.
- `expedientes.py`: registro, búsqueda, listado y ordenamiento.
- `archivos.py`: lectura y escritura de archivos.
- `validaciones.py`: validación de datos ingresados.

## Archivos generados
- `expedientes.csv`: almacena los expedientes registrados.
- `EXP-0001.txt`: ejemplo de una constancia generada.

Estos archivos se crean al utilizar las funciones correspondientes.

## Ejecución
Ejecutar `main.py` con Python 3 desde la carpeta del proyecto.
